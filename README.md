 Overview

This project contains a complete set of Business Analytics terminology notes, written in a clear, student-friendly format. The notes cover foundational concepts, data handling, customer metrics, and marketing analytics.

The goal of this project is to:

- Build a strong understanding of key analytics concepts
- Create easy-to-revise study material
- Demonstrate knowledge for a data analytics portfolio

---

 Contents

The notes are divided into 4 main sections:

 01. Foundational Concepts

Covers the basics of analytics, including:

- Business Analytics
- Data Analytics
- Business Intelligence (BI)
- Big Data
- Types of Analytics:
  - Descriptive
  - Diagnostic
  - Predictive
  - Prescriptive
- Data-Driven Decision Making
- Data Literacy

---

 02. Data, Measurement & Reporting

Focuses on how data is structured, stored, and presented:

- Structured vs Unstructured Data
- Data Warehouse
- Data Mining
- Data Visualization
- Dashboards
- Metrics & KPIs
- Benchmarking
- Segmentation

---

 03. Customer & Sales KPIs

Key business performance indicators:

- Conversion Rate
- Customer Acquisition Cost (CAC)
- Customer Lifetime Value (CLV)
- Churn Rate
- Retention Rate
- Net Promoter Score (NPS)
- Average Order Value (AOV)
- Sales Funnel

---

 04. Marketing & Campaign Analytics

Marketing performance and tracking:

- Marketing Campaigns
- Post-Campaign Analysis
- Incremental Revenue
- Return on Investment (ROI)
- Return on Ad Spend (ROAS)
- Click-Through Rate (CTR)
- Bounce Rate
- A/B Testing
- Lead Generation
- Marketing Attribution
